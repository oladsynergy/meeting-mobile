Deployment Instructions

To deploy your own signaling server:

  1. Navigate to the signaling-server folder in your app directory
  2. Follow the instructions in README.md
  3. For Oracle Cloud Free Tier, follow the step-by-step guide
  4. Once deployed, enter your server URL above
Important:
  • All users must connect to the same signaling server
  • Changes take effect for new meetings only
  • Users must restart the app after server URL changes
